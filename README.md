# Yoga Plus 🧘‍♀️

Um contador incremental simples criado com muito carinho para auxiliar nas práticas de yoga da minha namorada.

## Sobre o Projeto

O **Yoga Plus** é uma aplicação minimalista feita em HTML, JavaScript e Tailwind CSS, com o objetivo de servir como um contador de repetições, posturas ou tempos durante os exercícios de yoga. O projeto foi desenvolvido com foco em simplicidade, responsividade e leveza.

## Tecnologias Utilizadas

- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)
- [Tailwind CSS](https://tailwindcss.com/)
- HTML5
